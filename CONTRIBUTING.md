# Contributing

Thank you for wanting to help. This project welcomes contributions from everyone, including beginners.

---

## Ways to Contribute

- Report a bug by opening an issue
- Suggest a new tool or feature
- Improve the documentation
- Fix a typo or unclear sentence
- Add a new example question

---

## Reporting a Bug

Open an issue and include:

1. What you did
2. What you expected to happen
3. What actually happened
4. The full error message
5. Your operating system and Python version

The more detail you give, the faster it can be fixed.

---

## Suggesting a Feature

Open an issue and describe:

1. What the feature would do
2. Why it would be useful
3. Any ideas for how it might work

---

## Submitting a Change

1. Fork the repository
2. Create a new branch with a clear name
3. Make your changes
4. Test that everything still runs
5. Open a pull request with a short description

Keep changes focused. One pull request should solve one problem.

---

## Code Style

Keep it simple and readable. Write clear variable names. Add a short comment above any function that is not obvious. Prefer plain English over clever tricks.

---

## Code of Conduct

Be kind. Assume good intentions. Help beginners. This is a learning project and everyone was a beginner once.
